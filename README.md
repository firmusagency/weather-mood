# Weather Mood

Πλατφόρμα για ξενοδοχεία και τουριστικές επιχειρήσεις που μετατρέπει την πρόγνωση καιρού σε προτάσεις εκδρομών.
Το MVP καλύπτει τα **Χανιά (Κρήτη)**.

> Παράδειγμα: αύριο φυσάει δυτικός 4 Bf με κύμα 1,2 m → τα Φαλάσαρνα (κοιτάνε δυτικά) απορρίπτονται,
> προτείνονται Κολυμπάρι, Μαράθι και η ανατολική πλευρά της Παλαιόχωρας, που είναι προστατευμένα.

## Πώς δουλεύει

1. **Δεδομένα**: [Open-Meteo](https://open-meteo.com): άνεμος/ριπές από 5 μοντέλα (ECMWF, ICON, GFS, Météo-France, UK Met Office),
   θερμοκρασία/αίσθηση/βροχή/UV, και θαλάσσια πρόγνωση (κύμα, swell, θερμοκρασία νερού).
2. **Ανάλυση** (`src/engine/analysis.ts`): διάμεσος άνεμος των μοντέλων και πόσο διαφωνούν. Για κάθε παραλία υπολογίζεται
   αν ο άνεμος φυσάει προς την ακτή ή από τη στεριά, και πόσο από το κύμα των ανοιχτών φτάνει στην ακτή. Προστίθενται τοπικά φαινόμενα, π.χ. οι ριπές από τα βουνά στα Σφακιά με βοριά.
3. **Κρίση ανά προφίλ** (`src/engine/scoring.ts`): κάθε ώρα ξεκινά από 100 και χάνει πόντους για κάθε πρόβλημα, με τους αριθμούς του.
   Επιλέγεται το καλύτερο χρονικό παράθυρο. Η βαθμολογία καιρού είναι ξεχωριστή από τη σειρά πρότασης, η οποία λαμβάνει υπόψη και απόσταση, προφίλ και «σπάνια ευκαιρία».
4. **Προτάσεις** (`src/engine/recommend.ts`): 3 κορυφαίες επιλογές από διαφορετικές περιοχές, εναλλακτικές, και τι να αποφύγει κανείς.

## Οθόνες

| Σελίδα | Για ποιον | Τι δείχνει |
|---|---|---|
| `index.html` | Ξενοδόχος / host / reception | Πλήρης ανάλυση: 5 μοντέλα, θάλασσα ανά ακτή, βαθμός ανά σημείο, εξήγηση, μήνυμα για επισκέπτες |
| `guest.html` | Επισκέπτης (QR στο δωμάτιο) | Σελίδα για κινητό σε 4 γλώσσες (EL/EN/DE/FR): «Ποιοι ταξιδεύετε;», 3 προτάσεις, «Τι να πάρετε», οδηγίες χάρτη |
| `guest.html#lobby` | Οθόνη reception | Προτάσεις για αύριο για οικογένειες, ζευγάρια και πεζοπόρους, γλώσσες που εναλλάσσονται, QR |
| `guest.html#reception` | Προσωπικό reception | Φόρμα 20 δευτερολέπτων: «ο επισκέπτης γύρισε και είπε…» (μέρος, 👍/👎, τι δεν πήγε καλά) |

Τα στοιχεία του καταλύματος (όνομα, θέση, χρώμα, σύνδεσμος QR) βρίσκονται στο `src/guest/property.ts`. Το demo χρησιμοποιεί φανταστικό κατάλυμα.

Τα σημεία βρίσκονται στο `src/data/spots.ts`. **Είναι αρχική καταγραφή** (`verified: false`) και χρειάζονται επιτόπιο έλεγχο.

## Feedback επισκεπτών (το δεδομένο που δεν έχει κανείς άλλος)

Η σελίδα κινητού θυμάται τι προτείναμε και την επόμενη μέρα ρωτάει «Πήγατε; Πώς ήταν;» (👍 ή 👎 + κύμα/αέρας/κόσμος…).
Η reception καταχωρεί ό,τι της λένε οι επισκέπτες στο `guest.html#reception`. Κάθε ψήφος δένεται με την πρόγνωση που είχαμε δώσει
για εκείνο το μέρος και εκείνη τη μέρα.

- Αποθήκευση: Supabase (δωρεάν tier), πίνακες `feedback` και `visits`. Σχήμα: `supabase/migrations/0001_feedback_and_visits.sql`
  (τρέχει μία φορά στον SQL Editor του project). Το δημόσιο κλειδί στο `.env` μπορεί **μόνο να γράφει** (row-level security)·
  κανείς δεν διαβάζει ψήφους από τον browser. Χωρίς κλειδιά στο `.env` το feedback απλώς δεν εμφανίζεται.
- Το Action `.github/workflows/feedback.yml` τρέχει κάθε πρωί με το service key (secrets `SUPABASE_URL`, `SUPABASE_SERVICE_KEY`):
  ενώνει τις ψήφους με την αρχειοθετημένη πρόγνωση (`data/feedback/rows.jsonl`), γράφει τα σύνολα για το dashboard
  (`public/data/feedback.json`, καρτέλα «Μέθοδος & πηγές» → «Τι είπαν οι επισκέπτες») και την αυτόματη διόρθωση κύματος
  (`public/data/calibration.json`).
- Διόρθωση κύματος (`src/engine/feedback.ts`): όταν ένα σημείο έχει ≥ 8 ψήφους με πρόγνωση και οι επισκέπτες βρίσκουν συστηματικά
  περισσότερο (ή λιγότερο) κύμα από όσο είπαμε, ο συντελεστής κύματός του αλλάζει 5% ανά ψήφο, με όριο ±30–40%. Αέρας και κόσμος
  δεν διορθώνονται αυτόματα.
- Μετράμε και ανώνυμα ανοίγματα σελίδας (κινητό/οθόνη, γλώσσα, προφίλ) για την αναφορά χρήσης προς το κατάλυμα. Χωρίς προσωπικά δεδομένα.

## Εντολές

```bash
npm install
npm run dev            # εφαρμογή σε localhost
npm test               # σενάρια (δυτικός 4 Bf, μελτέμι, ζέστη, βροχή, προφίλ)
npm run report -- 2026-10-18 family chania   # αναφορά κειμένου από το τελευταίο snapshot
npm run demo:page      # dashboard ως ένα αρχείο HTML με ενσωματωμένα δεδομένα
npm run demo:guest     # οθόνες επισκέπτη ως ένα αρχείο HTML (VITE_GUEST_URL=... για το QR)
npm run snapshot:fetch # λήψη νέων δεδομένων (χρειάζεται πρόσβαση στο open-meteo.com)
npm run feedback:export # εξαγωγή ψήφων από τη βάση (SUPABASE_URL, SUPABASE_SERVICE_KEY) ή -- --from-file rows.json
```

## Δεδομένα και αυτοματισμός

- Το GitHub Action `.github/workflows/snapshot.yml` κατεβάζει δεδομένα κάθε 6 ώρες στο `public/data/snapshot-latest.json`.
  Κρατάει επίσης ένα αρχείο ανά ημέρα στο `data/archive/`, ώστε αργότερα να συγκρίνουμε τις προγνώσεις με την πραγματικότητα.
- Η εφαρμογή μπορεί να φέρει και ζωντανά δεδομένα απευθείας από τον browser (κουμπί «Ζωντανή ανανέωση»).
- Το Action `.github/workflows/verify.yml` τρέχει κάθε πρωί: συγκρίνει την πρόγνωση της προηγούμενης μέρας με τις μετρήσεις
  του σταθμού του αεροδρομίου Χανίων (LGSA, METAR) και ενημερώνει το `data/verification/` και το `public/data/verification.json`,
  που εμφανίζεται στην καρτέλα «Μέθοδος & πηγές» («Πόσο πέφτουμε μέσα»). Χειροκίνητα: `npm run verify -- 2026-10-18`.
- Το Open-Meteo είναι δωρεάν **μόνο για μη εμπορική χρήση**. Για πελάτες χρειάζεται συνδρομή API:
  ορίστε το secret `OPEN_METEO_API_KEY` στο repo.
